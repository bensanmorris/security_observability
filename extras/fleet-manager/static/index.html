Nodes

One row per cert-analyzer node Prometheus is scraping. Control says what this console can do on that node and, when it can't change anything, why: the node has no fleet-control code installed (cert-analyzer-control / the -control image), its [control] is off, the listener is on but unreachable from here, or the node accepts this console as a read-only client only. Hover a badge for the detail. Every node shows regardless.

Tetragon tracing policies

Rows are policies, columns are nodes. Each cell shows the state Tetragon reports on that node with an Enable/Disable button that acts on that node only; the row's All nodes buttons apply to every node in the row this console can change (the count is on the button; the rest are skipped and named in the result). Drift means the node's recorded decision and Tetragon disagree (the node will re-apply on its own). On a k8s node a change is a node-local override of the cluster-wide policy object.
